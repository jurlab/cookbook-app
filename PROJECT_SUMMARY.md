## 📊 How It Works

1. **Upload**: Take photos of cookbook index pages
2. **Process**: Claude Vision AI extracts recipes, ingredients, and page numbers
3. **Store**: Data saved to PostgreSQL database
4. **Search**: Find recipes by typing ingredients
5. **Track**: Rate recipes and count how many times you've cooked them
6. **Organize**: Merge duplicate ingredients to keep database clean

## ✨ Key Design Decisions

1. **Ingredient-First Indexing**: Mirrors how cookbook indices work
2. **AI OCR**: More accurate than traditional OCR for handwritten or fancy fonts
3. **Deduplication**: Same recipe under multiple ingredients handled automatically
4. **Progressive Enhancement**: Works locally first, deploy when ready
5. **Free Tier Friendly**: Designed to run on free hosting tiers
